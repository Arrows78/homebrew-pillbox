# Homebrew tap for Pillbox

[Pillbox](https://github.com/Arrows78/Pillbox) is a notch island for macOS: music, timers, clipboard, files and system alerts, one hover away.

## Install

```bash
brew install arrows78/pillbox/pillbox
```

Use the full name above. Homebrew 7 only loads casks from third-party taps you trust, and naming the tap in the command trusts that cask. If you ran `brew tap arrows78/pillbox` first, trust the tap before installing:

```bash
brew trust --tap arrows78/pillbox
brew install --cask pillbox
```

Update with `brew upgrade --cask pillbox`.

## First launch

Pillbox is signed ad hoc and not notarized, so macOS blocks the first launch. Open **System Settings › Privacy & Security** and click **Open Anyway**, or run:

```bash
xattr -dr com.apple.quarantine /Applications/Pillbox.app
```

## Uninstall

```bash
brew uninstall --cask pillbox         # keeps your settings
brew uninstall --zap --cask pillbox   # also removes Pillbox's settings
```

Your Keychain entries and your screenshots are never removed.

## About this repository

`Casks/pillbox.rb` is generated by the release workflow of the [Pillbox repository](https://github.com/Arrows78/Pillbox) on every release. Do not edit it by hand.
